# claude-skills

A Claude Code skill: `explain`.

| Skill | Purpose |
|---|---|
| `explain` | Technical explanation tailored to the reader's background, gauged by questions first |

## Install

```
git clone <this repo> ~/claude-skills
mkdir -p ~/.claude/skills
cp -r ~/claude-skills/explain ~/.claude/skills/
```

Invoke with `/explain <topic>`. To update later: `git pull`, then copy again.
